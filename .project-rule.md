# ZeroWall Project Directives
- Adhere strictly to C# WPF Desktop MVVM standards (`[AgentOption]/standards/csharp/wpf.md`).
- Implement and propagate `CancellationToken` end-to-end for all network and file I/O operations (`[AgentOption]/skills/csharp/cancellation-token-propagation.md`).
- Optimize memory and network allocations: recycle SkiaSharp bitmaps and leverage FIFO rolling cache for images.
- Adhere to the dual release packaging standard: support both Full (self-contained) and Lite (framework-dependent) deployment binaries.
